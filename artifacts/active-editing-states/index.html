Active editing state study

Four ways the workspace can behave while typing in Work Experience.

The layout stays fixed. These variations only change how much emphasis the active entry gets, how much the rest of the editor quiets down, and how much control chrome stays visible while the user is in a long editing session.

What changes

Active focus, secondary control reduction, surrounding context, and preview quieting are the only variables being explored here.

Study 01

Subtle Focus Elevation

Very restrained active state; inactive entries remain highly visible.

Study 02

Quiet Workspace Mode

Controls reduce while typing and the workspace becomes calmer.

Study 03

Structural Focus Mode

Stronger hierarchy, more compression, and clearer active emphasis.

Study 04

Immersive Editing State

The strongest focus mode, with the surrounding UI receding significantly.

All four keep the same left editor / right live preview architecture and the same Work Experience editing context.
