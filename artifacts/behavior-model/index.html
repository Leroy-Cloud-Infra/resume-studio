Resume Studio behavior model

How the product should behave while work is happening.

These pages are state studies, not visual concepts. They focus on document-first workflow, transient controls, structural navigation, and what the interface does during long editing sessions.

What to watch for

The document should remain primary. Controls should appear only when the user needs them, then recede. Navigation should follow structure and focus should stay with the content.

State 01

Refined workspace

Normal browsing and light editing, with the document in charge and the dock quiet.

State 02

Editing state

Active section editing, contextual controls, and inline focus near the content.

State 03

Navigation state

Structural movement through the resume, with a lightweight map and focus-follow behavior.
