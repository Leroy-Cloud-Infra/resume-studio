Control language refinements

Three quieter control treatments for the continuous editor.

The layout stays fixed. These variations only change the disclosure arrows, drag treatment, and visible action language so the editor feels more mature and production-ready.

Scope

No new flow. No new navigation model. Only the small control language that sits inside the stacked resume editor.

Variation 01

Quiet Disclosure + Hidden Handles

Plain structural chevrons, hidden handles, and hover-only affordance.

Variation 02

Whole Row Draggable

Rows do the dragging work; the handle disappears into the row itself.

Variation 03

Professional Action Reduction

Visible actions are condensed into quieter overflow and hover-only controls.

Each page keeps the same collapsed Header, Summary, Skills, and Education sections, with Work Experience expanded and live preview on the right.
