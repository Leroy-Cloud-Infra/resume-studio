Dense workspace refinements

Three calmer control treatments for the dense technical editor.

These are focused variations on the current dense workspace. The architecture stays the same, but the section navigation, framing, and guidance treatment are made flatter and more document-like.

What changed

Pills are replaced with document-native navigation alternatives. Floating card energy is reduced. Helper copy is turned into quieter status and operational hints.

Variation 01

Dense Workspace with Structural Outline

Quiet section outline, minimal framing, and a flatter editor shell.

Variation 02

Dense Workspace with Editorial Separators

Thinner dividers, continuous surfaces, and less visual boxing.

Variation 03

Dense Workspace with Focus Elevation

Only the active entry gets lift while the rest of the editor stays quiet.

All three keep the same editor / preview architecture and the same work experience test case.
