Editable surface comparison

Four surface shapes for the same continuous resume editor.

The layout and content stay fixed. These studies only change the shape of the editable surfaces so we can compare square, soft, rounded, and underline-first treatment in the same Work Experience context.

What changes

Field radius, border language, focus treatment, and bullet edit surfaces are the only variables in this comparison.

Variation 01

Refined Square

Mature, dense, and operational with minimal radius.

Variation 02

Restrained Soft Radius

Subtle radius and a strong candidate for the final system.

Variation 03

Rounded Editorial

More rounded and approachable, but watch the SaaS softness.

Variation 04

Borderless / Underline Hybrid

Document-integrated surfaces with text and lines as the main editable language.

All four keep the same left editor / right preview architecture, the same work experience structure, and the same content.
