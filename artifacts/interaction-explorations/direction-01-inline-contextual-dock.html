Inline Editing + Contextual Dock

Editing happens in the text flow. A small dock appears only when a section or paragraph is active, so the interface behaves like a writing surface with tools, not a tool surrounded by content.

Bullets are edited inline as well. When a bullet is selected, the dock shows only the edits relevant to that bullet: tighten, reorder, delete, or pin.

Long-session behavior The dock shrinks when idle, so the workspace stays readable after extended editing.
During long sessions, this model behaves like a writing app: the cursor stays in the document, the dock follows the current focus, and the page never hands over too much screen to persistent controls.
