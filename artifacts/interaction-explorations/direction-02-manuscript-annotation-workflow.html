Summary passage

IT support technician with six-plus years of experience across device support, account management, and network troubleshooting. The draft remains readable because commentary is attached to the text rather than stacked in a persistent side panel.

Editorial note This paragraph is strong enough to stay inline. The note is visible only while the passage is active.

Experience passage

Each role is treated like a passage with notes in the margins. The user can move through the document with keyboard shortcuts, then open only the revision controls that belong to the current passage.

Revision note If a role becomes too dense, the app asks the user to trim or collapse instead of introducing a new card section.

Long-session behavior

Over time, inactive notes collapse into a quiet trail. The document stays dominant, and the user can keep reading without feeling trapped by a fixed control layout.

Memory of edits Accepted changes remain visible in a soft history trail, so the interface can feel like a working draft instead of a form.
In long editing sessions, this model should feel like reviewing and revising a document: you jump to passages, open a note, accept a change, and move on without scanning a wall of controls.

Annotation rail

Guidance

Navigation

The user can move structurally or by note marker depending on task.

The app should preserve a trail of attention: what changed, what is pending, and which passage the user last touched.
