Summary

The summary is treated as a node in a larger document tree. Once it is active, the map highlights it and the inspector remains small unless the section needs attention.

Ambient guidance The map can show a small note badge when the section is underfilled or too dense.

Experience

Each role behaves like a structural block with its own focus state. The inspector appears only when the current block is selected, then recedes when the user keeps moving through the document.

Adaptive inspector The inspector should respond to the active block: one mode for editing, another for review, another for page-fit warnings.

Long-session behavior

Over a long session, the map becomes the memory of the document. It helps the user return to sections, preserve orientation, and move through the resume without opening large permanent sidebars.

Focus trail The app should preserve a quiet trail of where the user has been and what still needs work.
This model is meant to behave like a writing application with a structural spine: the outline helps navigation, the document remains primary, and controls appear only when the current section needs them.
